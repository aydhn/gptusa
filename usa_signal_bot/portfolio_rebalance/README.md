# Portfolio Rebalance, Turnover Control and Drift Management

This module provides tools and models to manage the drift between a target portfolio (generated by the Portfolio Construction engine) and a current portfolio (from paper trading or backtesting). It is designed to act strictly as a local metadata and reporting engine.

**IMPORTANT LIMITATIONS:**
- Does **NOT** execute real trades.
- Does **NOT** integrate with real broker APIs.
- Outputs are **NOT** investment advice.

## Components
- **Rebalance Models:** Core dataclasses defining `CurrentPortfolioState`, `TargetPortfolioState`, `DriftMeasurement`, `RebalanceAction`, `TurnoverAssessment`, `RebalancePlan`.
- **Drift Calculators:** Compute deviation at symbol, exposure (gross/net/long/short), and bucket (sector/regime/strategy) levels.
- **Turnover Control:** Caps absolute turnover and avoids dust (immaterial) actions.
- **Cost & Regime Throttles:** Uses transaction cost heuristics and regime state to suppress or review rebalance actions that might be too costly or risky to execute in the current environment.
- **Adapters:** Connects rebalancing to existing components like Paper Trading, Backtesting, Allocation, and Risk Reporting.

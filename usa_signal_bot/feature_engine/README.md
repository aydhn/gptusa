# Phase 116 Feature Factor Engine Foundation

This directory establishes the foundational elements for advanced indicators, features, and factor engines.
It operates purely as a metadata, schema, and planning layer.

**STRICT LIMITATIONS**:
- This phase DOES NOT compute actual technical indicators (this begins in Phase 117).
- It produces NO trade signals, and triggers NO automated order executions.
- It will NOT patch production configs or write to paper mutation states.
- It DOES NOT use paid APIs, external web scraping, or active dashboards.

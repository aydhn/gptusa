# Regime Map Engine

The Regime Map subsystem provides multi-timeframe and cross-sectional context for historical strategy evaluation.
It classifies individual symbols into trend, volatility, momentum, and liquidity regimes across daily, weekly, and monthly timeframes. It also assesses overall universe breadth and dispersion to establish market-wide contexts (e.g., Broad Uptrend, Risk-Off, Rotation).

## Core Concepts
- **Multi-Timeframe Confirmation:** Confirms if short-term behavior agrees with longer-term trends.
- **Cross-Sectional Regime Map:** Evaluates breadth and dispersion to contextualize individual signals.
- **Transition Risk:** Highlights potential structural shifts before they are fully established (e.g., breadth deterioration combined with volatility expansion).

## Disclaimer
- Output is for local historical research only.
- Confirmed regimes are heuristics, NOT investment advice.
- This module contains no live broker integration and produces NO real orders.

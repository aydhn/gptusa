# Local Market Calendar

**DISCLAIMER: NOT INVESTMENT ADVICE. NO BROKER/LIVE EXECUTION.**
This module provides a local, heuristic-based US Equities calendar for backtesting and signal awareness. It uses manual JSON files to define holidays and early close dates.

## Usage
`python -m usa_signal_bot calendar-info`
`python -m usa_signal_bot calendar-write-examples`
`python -m usa_signal_bot calendar-days --start 2024-01-01 --end 2024-01-31`

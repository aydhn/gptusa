# Phase 118 Limitations

Phase 118 is a local, offline research module only.
- It is NOT an activation mechanism.
- It is NOT a strategy or signal engine.
- It DOES NOT integrate with Broker APIs.
- It DOES NOT mutate paper state or portfolios.
- It DOES NOT parse HTML or scrape the web.
- It DOES NOT generate real Telegram messages.
- Test environments must not access real network resources.

All computed outputs are strictly local research datasets preparing the ground for Phase 119 event/calendar-aware feature enrichment.

# Market Impact Simulation

Market impact estimates the expected total adverse price movement generated by executing an order of a specific notional size against an asset's average daily volume (ADV).

## Characteristics
*   Heuristic simulation combining participation curves, spread costs, and volatility.
*   Classes range from NEGLIGIBLE to EXTREME.
*   EXTREME impact may be configured to block fill simulations.

## CLI Usage

```bash
python -m usa_signal_bot market-impact --symbol SPY --side buy --notional 1000 --adv 100000000
python -m usa_signal_bot fill-simulate --symbol SPY --side buy --price 100 --cost-bps 25
```

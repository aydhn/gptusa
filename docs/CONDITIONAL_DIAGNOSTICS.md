# Conditional Diagnostics

Diagnostics are created based on rule evaluations that provide context clues into regime overlaps.

## Diagnostic Types
- `LOW_COMPATIBILITY_DIAGNOSTIC`
- `UNCERTAIN_COMPATIBILITY_DIAGNOSTIC`
- `CONFLICTED_CONTEXT_DIAGNOSTIC`
- `DATA_QUALITY_LIMITED_DIAGNOSTIC`
- `CHURN_SENSITIVE_CONTEXT_DIAGNOSTIC`
- `LOW_STABILITY_CONTEXT_DIAGNOSTIC`

All diagnostics output only "research review" and "data quality review" recommended actions. No execution instructions are produced.

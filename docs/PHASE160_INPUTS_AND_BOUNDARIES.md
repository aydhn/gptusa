# Phase 160 Inputs and Boundaries

- **Phase160 Handoff Package**: Phase 159'dan gelen, `read_only` bayrağı aktif veri paketi.
- **Final Freeze Certificate**: Değişim kod/konfig bandının dondurulduğunu gösterir.
- **Risk Register & Evidence Bundle**: Kabul kanıtlarının (test, audit) toplandığı girdi listesi.
- **Forbidden Fields**: `live_order`, `buy_signal`, `actual_allocation`, vb. Bu alanların varlığı Phase 160 safety kontrollerini derhal bloke eder.

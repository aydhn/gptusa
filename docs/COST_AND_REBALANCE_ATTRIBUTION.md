# Cost and Rebalance Attribution

## Cost Attribution
Calculates the performance drag generated by costs. Dimensions can be analyzed by components such as `Slippage`, `MarketImpact`, and inferred `FeesAndCommissions`. Cost attribution is critical for identifying strategies that look good on paper but fail under execution realism guards.

## Rebalance and Turnover
Rebalance attribution tracks the PnL and costs explicitly associated with portfolio rebalance actions (e.g., `INCREASE`, `DECREASE`, `EXIT`). High turnover strategies often generate substantial cost drag, which this module highlights.

## CLI Usage
```bash
python -m usa_signal_bot cost-attribution --dimension cost_component
python -m usa_signal_bot rebalance-attribution
python -m usa_signal_bot sizing-attribution
```

# Indicator, Feature, and Factor Registries

The registries organize metadata regarding all computed features.
Each definition states what it takes as input and what it outputs.

- **IndicatorRegistry**: Price-based, Volume-based, Momentum, and other fundamental metrics.
- **FeatureRegistry**: Intermediate, derived, or cross-sectional data types.
- **FactorRegistry**: Abstracted factor signals that describe regimes or momentum scores.

**Warning:** Factor outputs are metadata values for research correlation and strategy filtering. They are **NOT** trade recommendations.

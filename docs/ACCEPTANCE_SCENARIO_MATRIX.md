# Acceptance Scenario Matrix

The scenario matrix defines all areas that require regression and safety validation:
- Full Chain Dry-Run Regression
- Config and Runtime Compatibility
- Data Provider Safety Boundary
- Feature Engine Schema Validation
- Regime Engine Dry-Run
- ML Governance Safety Check
- Backtest Closure Consistency
- Portfolio Band Governance
- Integration Boundary Safety
- Notification Dry-Run
- Quality and Observability Metrics
- Final Delivery Precheck

All scenarios run with `dry_run=True` and `local_fixture_only=True`.

# Non-Activation Ensemble Registry

A local repository of evaluated ensemble prototypes.

- Features entries tracking predictions, evaluations, and blend diagnostics.
- Used to establish a baseline for Phase 144 model drift tracking (`eligible_for_phase144_drift_baseline=True`).

**Explicit Non-Activation Rules:**
- `eligible_for_live_use=False`
- `eligible_for_paper_use=False`
- `eligible_for_broker_use=False`
- `eligible_for_deployment=False`
- `eligible_for_strategy_activation=False`

This is a research registry, NOT a deployment registry.

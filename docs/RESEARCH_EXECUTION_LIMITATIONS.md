# Research Execution Limitations

This system is built under strict parameters as a **local analytics tool only**.

1. **Local Analytics:** Research execution is strictly local analytics.
2. **No Performance Guarantees:** Mock/backtest/walk-forward results do NOT guarantee future performance.
3. **No Automatic Patching:** No automatic production config patching is performed.
4. **No Optimizer:** No automatic parameter optimization is executed.
5. **No Broker Integration:** No live or demo broker orders are generated.
6. **No Live Approval:** A `PASS` outcome or `CANDIDATE_BETTER` report is NOT a live trading approval.
7. **Not Investment Advice:** This output is NOT investment advice.

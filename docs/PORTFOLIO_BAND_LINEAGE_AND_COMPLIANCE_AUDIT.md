# Portfolio Band Lineage and Compliance Audit

Lineage tracks artifacts generated throughout Phase 153 to Phase 157.
The compliance audit enforces system safety checks across the entire band.

## Constraints
- **Lineage Chain:** Requires foundation, sizing prototypes, allocation sandbox, optimizer sandbox, and closure artifacts.
- **Deterministic Hashing:** All artifacts must produce a deterministic hash.
- **Strict Prohibition:** All live, paper, and broker executions are rigorously denied during the audit.

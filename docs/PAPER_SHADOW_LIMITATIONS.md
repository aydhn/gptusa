# Paper Shadow Limitations

This subsystem operates entirely locally and is explicitly designated as a simulation.

- **Not Real Trading:** Shadow order intents are not real orders.
- **Not Real Fills:** Shadow fills are simulated.
- **No Broker API:** This system does not communicate with any broker.
- **No Paper Mutation:** The existing paper trading state is never modified.
- **No Telegram Real Send:** Notification previews are generated, but not sent.
- **Not Investment Advice:** A PASS in the shadow rehearsal is NOT an approval for live trading or financial advice.

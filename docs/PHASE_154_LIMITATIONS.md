# Phase 154 Limitations

1. **Prototype Sizing Only**: Generates fractions for research. It is explicitly NOT an actual position sizing process.
2. **No Allocation**: It produces NO `target_weight`, `allocation`, `order_size`, or `capital_allocation`.
3. **No Execution**: Live, paper, and broker integrations are strictly forbidden.
4. **Not Investment Advice**: The output is purely for technical validation.
5. **Phase 155 Preparation**: Passing Phase 154 only unlocks the allocation sandbox for Phase 155 development.

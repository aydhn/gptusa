# Reliability Binning and Expected Calibration Error (ECE)

Calculates reliability bins and expected calibration error to diagnose over/under-confidence.

## Features
- **Fixed 10-bin reliability:** Default approach for grouping probabilities.
- **Metrics computed:**
  - Average confidence
  - Empirical accuracy
  - Calibration gap
  - Expected Calibration Error (ECE)
  - Maximum Calibration Error (MCE)

*Note: Binning is NOT calibration fitting.*

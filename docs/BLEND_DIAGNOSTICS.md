# Blend Diagnostics

Diagnostics run on offline blend specifications:
- **Coefficient Sum Check:** Ensures weights sum correctly.
- **Coefficient Range Check:** Validates normalized limits.
- **Contribution Balance:** Checks for skewed candidate reliance.
- **Dominant Candidate Check:** Identifies over-represented candidates.
- **Candidate Coverage Check**
- **Missing Candidate Output Check**

**Important Note:** Blend coefficients are explicitly NOT portfolio weights, allocations, or target weights. They are ML ensemble prediction weights only.

# Lifecycle Management Limitations

Because this project is strictly bound to run locally without paid APIs, real broker access, or web scraping, the **Universe Lifecycle and Survivorship-Bias Guard** subsystem has several crucial limitations:

1. **No Official Guarantee:**
   The system relies on local manual JSON registries and caching. It is **NOT** connected to an official stock exchange delisting database.

2. **Operator Dependent:**
   The `symbol_lifecycle_registry.json` and `symbol_aliases.json` files must be populated manually or inferred. The system will do its best to infer statuses from stale historical data, but this inference is imperfect.

3. **Not Investment Advice:**
   Any `survivorship_bias_score` or `universe_guard_status` generated by this system is an **operational research metric**. It does NOT constitute financial or investment advice.

4. **Not Live Trading Approval:**
   A `PASS` or `CLEAR` status from the lifecycle guard does NOT mean the symbol is safe or approved for real-world trading. There is strictly no live execution.

5. **No Web Scraping:**
   The system deliberately avoids using `BeautifulSoup`, `Selenium`, or any HTML parsing to automatically hunt for corporate news or delisting announcements.

# Sandbox Limitations

Sandbox mode actively works to create a deterministic dry-run of operations isolated away from the production environment inside the USA Signal Bot framework.

* **The sandbox is a local preview representation only.**
* **It acts neither as an approval for live usage or production activation.**
* **Previews don't enforce paper usage directly locally without active confirmations mapping later down the execution flow.**
* **Previews do not generate telegram signals via network bindings actively.**
* **Evaluated metrics act strictly as mock assumptions, and output configurations do not execute internet validations.**

The evaluation is not investment advice or future representation guarantee, generating only isolated read-only models.

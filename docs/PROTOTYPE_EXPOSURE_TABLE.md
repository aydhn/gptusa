# Prototype Exposure Table

## Structure
The table aggregates individual records capturing:
- `sandbox_prototype_weight`: Initial sandbox weight.
- `normalized_sandbox_weight`: The scaled fractional weight relative to other components.
- `group_sandbox_weight`: The aggregated category level weight bounds.

## Restrictions
Under no situations should exposure parameters be construed as real limits. The dataset prevents derivation of attributes associated with:
- Actual Exposure Boundaries
- Target or Actual Capital Allocations
- Position or Order Resizing Execution

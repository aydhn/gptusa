# Attribution Limitations

--- ATTRIBUTION LIMITATIONS ---
1. **Local Analytics:** This is a local backtest/paper attribution analytics layer ONLY. It operates entirely offline using available data.
2. **Not Real Performance:** These metrics do NOT represent real broker performance.
3. **No Financial Advice:** High attribution scores, positive signal contributions, or robust risk metrics are NOT investment advice.
4. **No Live Execution:** A PASS validation or high scorecard rating is NOT a live trading approval. The system generates no actual broker commands.
5. **No Guarantees:** Past performance attribution does not guarantee future results.
6. **Heuristics:** Risk attribution models are basic proxies (e.g., sum of absolute PnL) and do not utilize advanced statistical libraries.

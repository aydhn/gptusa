# Session Awareness

**DISCLAIMER: NOT INVESTMENT ADVICE. NO BROKER/LIVE EXECUTION.**
This module classifies dates and timestamps into specific market sessions: PREMARKET, REGULAR, AFTER_HOURS, WEEKEND, HOLIDAY, EARLY_CLOSE, or CLOSED.

## Usage
`python -m usa_signal_bot calendar-session --date 2024-01-02`
`python -m usa_signal_bot calendar-validate-rows --symbol SPY`

# Readiness Rehearsal Limitations

- The Readiness Rehearsal generates **local metadata only**.
- A Final Review Lock is **not a deployment approval**.
- The Guarded Handoff Registry **does not constitute active paper, live, or demo approval**.
- There is **no broker API connection**.
- There is **no real paper state mutation**.
- There is **no Telegram real send**.
- The outputs do **not constitute investment advice**.

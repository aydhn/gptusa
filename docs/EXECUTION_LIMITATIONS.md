# Execution Limitations

1. **NO Live Orders**: The bot does not use any broker APIs.
2. **NO Actual Executions**: Live trading approval is explicitly forbidden.
3. **NO Real Order Book**: Spreads and slippage are computed as synthetic proxies.
4. **NO Actual Borrow**: Short selling capability is inferred, not based on real locate tools.
5. **NO Investment Advice**: Findings are entirely operational/heuristic in nature.

# Feature/Factor Final Data Contract

The final data contract outlines the allowed boundaries for the feature/factor engine (Phase 116).

## Allowed Input Kinds
- OHLCV metadata
- Event/Impact context
- Quality and Lineage metadata

## Blocked Output Kinds
- Trade signals
- Order decisions
- Broker execution payloads
- Paper state mutations
- Telegram sends, scraping, paid API payloads

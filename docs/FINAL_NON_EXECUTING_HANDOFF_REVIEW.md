# Final Non-Executing Handoff Review

The final non-executing handoff review evaluates readiness rehearsal data and guarded handoff registry entries to determine if a candidate is ready for a sealed readiness archive.

**Important Limitations:**
- This is NOT an active paper enable step.
- No broker orders or live executions are authorized.

CLI Usage:
```
python -m usa_signal_bot final-handoff-info
python -m usa_signal_bot final-handoff-review --write
```

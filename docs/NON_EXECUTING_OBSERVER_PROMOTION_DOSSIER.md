# Non-Executing Observer Promotion Dossier

## Purpose
The Promotion Dossier compiles evidence and readiness metadata for an observer candidate. It verifies evidence completeness across observation, controlled planning, quarantine, and shadow governance.

## Limitations
- **NOT an active paper activation:** This dossier simply generates metadata indicating read-only staging potential.
- **No Broker API / No Live Orders:** Order routing and broker interaction are strictly prohibited.
- **No Production Config Patch:** The candidate configuration is not automatically pushed to production.

## Commands
- `python -m usa_signal_bot promotion-dossier-info`
- `python -m usa_signal_bot promotion-dossier-build --write`

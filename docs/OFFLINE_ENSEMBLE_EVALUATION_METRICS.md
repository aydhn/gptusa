# Offline Ensemble Evaluation Metrics

Metrics calculated offline for research purposes:
- **Classification:** Accuracy, Balanced Accuracy, F1 Macro
- **Regression:** MAE, RMSE, R2
- **Ranking:** Rank Correlation
- **Calibration:** Brier Score
- **Diagnostics:** Agreement Coverage, Blend Stability, Contribution Diversity

**Prohibited Metrics:**
PnL, trading returns, backtest metrics, and financial performance metrics are entirely omitted. The evaluation metric outputs are not investment advice.

# ML Leakage Audit

A comprehensive leakage check performed on assembled matrices and splits.

- Future Data Leakage Check
- Target Leakage Check
- Label Overlap Check
- Timestamp Alignment Check
- Train/Validation/Test Overlap Check
- Embargo/Purge Check
- Forward Window Overlap Check
- Forbidden Output Field Check

If the leakage audit fails, Phase 138 readiness is blocked.

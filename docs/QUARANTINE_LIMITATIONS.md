# Quarantine Limitations

The Paper Quarantine system operates strictly as a local governance and metadata tracking layer.

## Explicit Limitations
1. **Not Investment Advice**: Enrollment, high scores, or tickets do not constitute financial advice.
2. **No Broker Integration**: There is zero interaction with real or demo broker APIs.
3. **No Active Paper Trading**: Quarantine is not activation. No real paper orders or state mutations occur.
4. **No Telegram Dispatches**: Notifications are preview-only.
5. **No Production Patches**: System configuration files are never automatically altered.
6. **No Machine Learning Optimization**: The evaluation and eligibility process relies on deterministic rules, not ML or auto-tuning.
7. **Read-Only Context**: Snapshots and tickets are strictly read-only references.

# Regime Behavior Summary

The Regime Behavior Summary condenses behavior profiles into human-readable narratives.

## Summaries Generated
- **Transition Summary**: Highlights transition matrix concentrations.
- **Persistence Summary**: Explains sequence run-lengths heuristically.
- **Duration/Churn Summary**: Describes label churning contexts.
- **Stability Summary**: Analyzes rolling window disagreement.
- **Confidence / Data-Quality Summary**: Explains instances of fallback/unknown states.

### Disclaimer
Summaries are NOT investment advice. No language will be generated suggesting guaranteed performance or recommending a buy/sell action.

# PHASE 136 - Advanced ML Foundation

This phase marks the beginning of the Advanced ML band (136-145). It establishes the read-only dataset contracts, governance rules, and leakage guard boundaries.

**Limitations**:
- No model training in Phase 136.
- No model prediction in Phase 136.
- Dataset assembly is deferred to Phase 137.
- No execution, order routing, or paper mutations.
- No heavy ML dependencies (sklearn, torch, xgboost) are required here.

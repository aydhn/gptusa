# Rebalance Limitations

1. **Local Metadata Only:** The plan generated does NOT execute live trades.
2. **No Real Orders:** It has no awareness of real broker fill states.
3. **No Advice:** It does NOT constitute financial advice.
4. **Heuristics:** Cost and market impact estimations are proxies.
5. **No Optimization Models:** Uses heuristic rule thresholds rather than mean-variance/MVO.

# Model Card Drafting

## Overview
Generates documentation artifacts (model cards) detailing the model's purpose, dataset, evaluation, and limitations.

## Sections
- Model Purpose
- Dataset Scope
- Training Status
- Limitations
- Safety Boundary
- Governance

## Important Flags
- `training_not_started = True`
- `not_investment_advice = True`
- `not_trade_signal = True`
- `not_deployment_artifact = True`
- This is a draft model card and does not contain trained weights or final performance metrics.

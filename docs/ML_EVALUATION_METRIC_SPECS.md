# ML Evaluation Metric Specs

## Supported Metrics
- **Classification**: Accuracy, Balanced Accuracy, F1 Macro.
- **Regression**: MAE, RMSE, R2.
- **Others**: Rank Correlation, Calibration Brier Score, Confusion Matrix, Stability Metric.

## Constraints
- These metrics are purely statistical/ML-based.
- They are **NOT** PnL, backtest, or trading metrics. Those are reserved for Phase 146+.

# Regime, Calibration, and Ensemble Explanations

The proxy architecture extends to advanced evaluations:

- **Regime-Aware Explanation**: Summarizes metadata behaviour across regimes. This is a descriptive insight, not a strategy switch mechanism.
- **Calibration-Aware Explanation**: Notes alignment of probabilities, decoupled from any active threshold optimization or calibration fitting.
- **Ensemble Explanation**: Analyzes blend metadata and candidate contributions without creating actionable portfolio allocations.

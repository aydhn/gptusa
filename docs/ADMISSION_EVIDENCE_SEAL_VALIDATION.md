# Admission Evidence Seal Validation

This module validates the evidence seal from Phase 87. It checks for:
- Hash match: Ensures the payload hash matches the expected hash.
- Sealed: Ensures the seal is marked as sealed.
- Immutable: Ensures the seal is marked as immutable.

The seal refresh generated by this module is metadata-only and DOES NOT constitute an active paper deployment.

## CLI Commands
- `python -m usa_signal_bot evidence-seal-validate --write`
- `python -m usa_signal_bot evidence-seal-refresh --write`

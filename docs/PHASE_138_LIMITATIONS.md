# Phase 138 Limitations

- **Not a Trading Engine**: Does not activate strategies or route orders.
- **Not a Training Pipeline**: Does not train models or execute predictions. Actual baseline models will be generated in Phase 139.
- **Strict Data Access**: Operates offline based purely on the previous phases' artifacts.
- **No Heavy ML Frameworks**: Libraries like PyTorch, Scikit-Learn, XGBoost, and LightGBM are explicitly forbidden in execution paths for this phase.

# Human-Gated Paper Readiness Board
Evaluates candidate strategies using readiness confirmation reviews, human review bundles, and the activation-still-denied registry. A PASS from this board is **NOT** an active paper trading or live execution approval.
## Limits
- No real broker execution.
- No active paper enable.
- No real mutation.
## Commands
`python -m usa_signal_bot paper-readiness-board-info`
`python -m usa_signal_bot board-gates --write`
`python -m usa_signal_bot board-decision --write`

# Phase 120 Limitations

- Phase 120 is strictly non-activating. It only prepares configurations for factor computations.
- Real factor computations occur in Phase 121.
- Signal generation and strategy matching occur in later bands.
- Broker APIs, Demo APIs, paper state mutations, live orders, scraping, HTML parsing, web dashboard engines, and paid APIs are explicitly forbidden.
- Output artifacts generated during Phase 120 represent structured research metadata only, and they do not constitute financial advice.
